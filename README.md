# HybridGrainTool
Hybrid rocket engine fuel grain regression simulator that supports arbitrary circular- and star- shaped geometries.

---
To install and use:
1) Ensure all required packages are installed (see below)
2) Download hybridgraintool.py
3) Run hybridgraintool.py

---
Required packages:
* time
* math
* tkinter
* PIL
* matplotlib
* numpy
* cv2
* skfmm
